# راهنمای سایت شخصی امیر همت

این پوشه شامل یک سایت استاتیک و واکنش‌گرا برای معرفی **Amir Hemat / Amirreza Hematian** است. سایت با HTML، CSS و JavaScript خام ساخته شده و برای اجرا به نصب وابستگی یا فرایند build نیاز ندارد. محتوای قابل‌مشاهده سایت انگلیسی است.

## افزودن عکس شخصی

فایل عکس خود را با نام دقیق `portrait.jpg` در این مسیر قرار دهید:

`/assets/images/portrait.jpg`

یعنی در کنار پوشه‌های `css` و `js`، پوشه `assets/images` را باز کنید و عکس را همان‌جا ذخیره کنید. تصویر با نسبت عمودی بهتر نمایش داده می‌شود. اگر عکس در مسیر نباشد، صفحه به‌جای تصویر خراب، جای‌نگهدار گرافیکی با حروف اول نام را نشان می‌دهد. فایل عکس از قبل ساخته نشده است.

## اجرا با VS Code و Live Server

1. پوشه `portfolio-amirreza-hemmat...` را در VS Code باز کنید (نام پوشه ممکن است بسته به محل دریافت فرق کند).
2. از بخش Extensions افزونه **Live Server** را نصب کنید.
3. روی `index.html` راست‌کلیک کنید و **Open with Live Server** را بزنید.
4. سایت در مرورگر باز می‌شود؛ با ذخیره تغییرات، صفحه را بازبینی کنید.

همچنین می‌توانید `index.html` را مستقیماً در مرورگر باز کنید؛ Live Server برای بازبینی راحت‌تر پیشنهاد می‌شود.

## انتشار در وب

پس از آماده‌کردن عکس و بازبینی محتوا، فایل‌ها را روی یک میزبان استاتیک منتشر کنید؛ برای نمونه GitHub Pages (پس از ساخت حساب و مخزن)، Netlify یا Cloudflare Pages. پوشه‌ای که `index.html` در ریشه آن است را به‌عنوان پوشه انتشار انتخاب کنید. چون سایت build لازم ندارد، فایل‌ها را می‌توان مستقیم منتشر کرد. قبل از انتشار، لینک‌های تماس، نمایش موبایل و دسترسی‌پذیری را بررسی کنید؛ برای استفاده از دامنه اختصاصی نیز DNS دامنه را طبق راهنمای میزبان تنظیم کنید.
